# 小米15充电加速

适用于小米15（dada，骁龙 8 至尊版）的 KernelSU / Magisk 模块。作者：酷安@鱼楠

- 当前版本：v8.4.8（versionCode 848）
- 刷入包：`releases/小米15充电加速_v8.4.8.zip`
- 模块源码：`module/`

功能：DTBO 充电参数修改（电流、FFC 温区、关机电压等，自动备份原厂镜像）、公版 PPS 解锁、高刷切换、温控解除、充电日志与 WebUI，内置充电监测 App。

致谢：酷安@低线阻狂魔、酷安@花橋桥（PPS 节点）、酷安@瓦力喀 / FreePPS（思路参考）

> 修改 DTBO 有风险，刷入前请确认机型与系统版本，并保留原厂 dtbo 备份。
